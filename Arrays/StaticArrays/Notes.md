--> *Static array* = a fixed-size collection of elements stored in contiguous memory, where size is known at compile time.
1️⃣ Fixed size
2️⃣ Same data type elements
3️⃣ Index starts from 0
4️⃣ Contiguous memory
5️⃣ Fast random access → O(1)

--> *Dynamic array* = array jiska size runtime pe decide hota hai aur memory heap se milti hai.
1️⃣ Pointer banta hai (stack pe)
2️⃣ Heap se memory allocate hoti hai
3️⃣ Pointer us memory ko point karta hai
